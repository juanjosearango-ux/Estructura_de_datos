# Laboratorio 4: Quadtree vs Fuerza Bruta

Implementación en Python de una estructura de datos espacial (Quadtree) para la gestión eficiente de puntos de entrega en 2D, comparando su rendimiento frente a la búsqueda por fuerza bruta.

## Estructura del Repositorio
- `Quadtreetree.py`: Implementación de las clases `Rectangle` y `Quadtree` (inserción, búsqueda por rango y vecino más cercano).
- `analisis.py`: Script de pruebas comparativas de rendimiento para distintos tamaños de datos ($N$).
- `test.py`: Pruebas unitarias de validación y generación de gráficas de verificación visual con Matplotlib.
- `range_search_plot.png` / `nearest_neighbor_plot.png`: Gráficas de resultados visuales.

## Requisitos
- Python 3.x
- Matplotlib (necesario para la ejecución de las pruebas visuales en `test.py`)

## Ejecución
Para correr las pruebas unitarias y generar las gráficas:
```bash
python test.py
